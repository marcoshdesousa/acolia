SEU CÓDIGO ÚNICO

Este é o seu código de login. Não compartilhe com pacientes — para eles você gera um código próprio abaixo. Você pode ter até 2 atendimentos abertos ao mesmo tempo; entre em cada um pelo botão Entrar na chamada.

Criar atendimento

Gera um código para o paciente (começa com os 2 primeiros caracteres do seu código). Envie para ele pelo chat ou como preferir. Ao finalizar o atendimento, o código deixa de funcionar.
